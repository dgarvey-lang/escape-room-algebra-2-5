# Escape the Radical Manor

A Halloween-themed escape room for Algebra 2 (section 2-5): solve quadratics by square roots and rationalize every denominator to collect five treasures and escape.

- **Rooms:** `ax² = b`, `ax² + k = c`, `a(x − h)² = b`, `a(x − h)² + k = c`, and imaginary solutions.
- **Help:** step-by-step ghost hints, a spellbook, and an ungraded Pumpkin Patch practice room.
- **Completion:** students earn an escape code tied to their name; use the **Teacher** link at the bottom of the page to verify a name/code pair.

## Running it

Everything is in a single file, `index.html`. Open it in a browser, or enable GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder) to get a link for students.

Progress is saved in the student's browser (`localStorage`), so it stays on that device.
